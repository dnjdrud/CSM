# 3단계 — 방 1~3
## 방1 아직 화가 나요
예외: 녹음/동의 없음.
‘아직 많이 화가 나실 수 있어요. 서운하고 답답하고, 지금은 아들의 이야기를 듣고 싶지 않으실 수도 있어요. 여기서는 마음을 바로 정리하지 않으셔도 괜찮아요. 우선 어떤 마음인지 적어두셔도 돼요.’
[내 마음 적기]. 제목 선택/본문 필수. [나만 간직하기]와 [아들에게 전하기]를 저장 전에 명확히 선택, 기본 선택하지 않는다.
개인글은 별도 비밀번호 보호 및 실제 아들 열람 불가. 전달글은 최종 확인 후만 아들에게 공개. 초안/다시 읽기/저장·삭제 제공. 욕설을 유도하지 않는다. 아들 알림에 본문 자동 표시 금지.
## 방2 네 마음을 들어볼게
안내 순서:
1 ‘이 방은 아들이 엄마와 아빠에게 자신의 마음을 전하고 싶어서 만든 공간이에요.’
2 ‘아들은 자신의 마음을 궁금해해 주시는 것이 감사해요. 한편으로는 이야기를 꺼냈다가 다시 비난받을까 봐 두렵기도 해요.’
3 ‘지금은 아들의 마음을 먼저 들어보고 싶으신가요?’
최종 입장 녹음: ‘네 마음을 들어보고 싶어.’
본문 카드: 고마웠던 마음/미안했던 마음/파혼을 겪던 마음/그날 들었던 말/말을 꺼내기 어려웠던 이유/그래도 바라는 것.
배경 자료를 기반으로 1인칭 편지 초안 작성. 사실·감정 구분, 부모 의도 단정 금지. 외모 비하와 여자친구 욕설로 상처받았고 사과받길 바란다는 점을 축소하지 않는다. 모든 카드 읽기 강제 없음.
## 방3 다시 믿을 수 있을까
사전 안내 ‘이 방은 아들이 부모님과의 신뢰를 다시 쌓고 싶어서 만든 공간이에요.’
‘찾아와주신 엄마와 아빠에게 아들이 짧은 편지를 썼어요. 읽어보시겠어요?’→[편지 읽기].
사전 편지 후 ‘읽어주셔서 감사해요.’→‘어머니는/아버지는 제가 어떤 모습을 보여드리면 조금씩 안심하실 수 있을까요?’
[생각 적어두기] 선택, [노력 살펴보기] 선택 시 바로 입장하지 말고 최종 녹음.
녹음: ‘네가 어떤 노력을 하고 있는지 살펴볼게.’
본문 카드: 건강을 돌보는 노력(다이어트)/재정 안정화/차용금 상환 준비. 각 현재 하는 일·확인된 변화·다음 계획. 실제 기록 없으면 준비 중으로 표시. 목표를 성과로 위장하지 않는다.
3번 사전 편지는 게이트 이전 허용, 노력 카드 본문은 게이트 이후만. 관리자도 각 부모의 개인글을 볼 수 없도록 한다.
