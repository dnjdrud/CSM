## 사용자 최신 수정 — 로그인 단순화
엄마 또는 아빠 선택 → 각자 비밀번호 입력 → 입장으로 구현한다. 기기 등록/인증/기억/자동 로그인/추가 PIN 설정을 만들지 않는다. 아빠 비밀번호는 아들 생년월일 8자리, 엄마 비밀번호는 아들 휴대폰 뒤 4자리다. 서버 환경변수에서 검증하고 프런트엔드에 비밀값을 넣지 않는다. 일반적인 세션 및 계정별 접근 권한은 유지한다. 개인글 전용 암호화 비밀번호는 로그인과 별개 기능으로 유지한다.
