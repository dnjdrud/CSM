# 마음이 닿는 집 — 확정 요구사항
## 목적
부모님이 원할 때 선택적으로 아들의 마음과 현실적인 계획을 읽고 관계 회복을 준비하는 가족 전용 모바일 웹. 고동색 배경. 엄마/아빠 별도 계정. 부모의 마음을 점수화하지 않으며 순차 클리어를 강제하지 않는다.
## 첫 방문
로그인 후 1. 공간을 만든 이유와 읽을 시점 선택 안내 2. 짧은 편지 3. 사용 설명 4. 일곱 방 목록. 자동 전환 없이 매 화면 큰 버튼을 누른다. 첫 방문 안내는 다시 열 수 있다.
도입: “엄마, 아빠. 직접 이야기하면 서로 마음이 더 다칠까 봐, 제 마음을 천천히 전할 수 있는 공간을 만들었어요. 지금 바로 읽지 않으셔도 괜찮아요. 읽고 싶은 날, 읽고 싶은 만큼만 봐주세요. 바로 답하거나 어떤 결정을 내리지 않으셔도 괜찮아요.”
## 방 입장 — 최신 수정이 최우선
1번 방은 예외로 별도 동의/녹음 없이 입장한다.
2~7번은 안내 문장을 버튼으로 차례로 보고 필요한 사전 편지/생각 질문을 읽는다. 그 뒤 방에 들어가기 직전에 반드시 이번 입장을 위한 녹음을 새로 만든다. 녹음→정지→전체 재생→본인 확인→본문 입장. 다음 방문과 다른 방 이동 후 재입장도 매번 반복한다. 앱 내 본문 읽기/카드 이동은 재입장이 아니다. 새로고침/세션 복원/직접 URL 접근 시 입장 권한 재확인한다.
“녹음 대신 글로 확인”, “이미 열었던 방 바로 입장”, 저장 녹음 재사용 기능을 절대 만들지 않는다. 마이크 거부/미지원은 안내·재시도·방 목록 복귀만 제공한다.
## 계정
아빠 비밀번호: 아들 생년월일 8자리(19980122). 엄마 비밀번호: 아들 휴대폰 뒤 4자리(미제공). 실제 비밀번호는 서버 환경변수로 주입. 엄마 코드 임의 생성/추측 금지. 관리자 아들 계정은 별도 강한 자격증명. 공개 가입 없음. 부모 각각 데이터 격리. 기기 등록·기기 기억·신뢰 기기·자동 로그인 기능은 구현하지 않는다. 엄마/아빠 선택 후 각자 비밀번호만 입력한다. 로그인 상태 유지를 위한 일반 세션만 사용하고 로그아웃하면 비밀번호를 다시 입력한다.
## 콘텐츠 원칙
감사/구체적 사과/상처/책임/요청을 구분. 외도에 따른 파혼을 아들의 도덕적 잘못으로 서술하지 않는다. 외모를 개선해야 사랑받는다고 서술하지 않는다. 부모 동기를 체면으로 단정하지 않는다. 죽음 관련 표현을 사과나 입장을 강요하는 수단으로 사용하지 않는다.
확인된 배경: 2026-06-06 파혼, 아들이 전달한 원인은 상대방 외도. 주택 매수가 682,500,000원, 증여 150,000,000원, 차용 540,000,000원, 월 약정 1,575,000원. 자금 용도가 달라 단순 합산하여 집값/손실로 표기 금지. 실제 상환 내역/결혼 예산/일정은 미확정이며 생성 금지.
## 개인정보
‘나만 간직하기’는 아들/다른 부모가 실제로 읽을 수 없어야 한다. 운영자가 몰래 보는 기능 금지. 별도 비밀번호를 이용한 클라이언트 암호화로 구현하고 비밀번호/키는 서버로 보내지 않는다. 복구 불가 안내. 아들에게 전한 글은 작성자와 아들만 열람한다. 입장 녹음은 서버 전송/저장하지 않고 메모리에서만 처리 후 삭제. 방문 추적/읽음 알림/감정 점수 없음.
## UI
고동색 #3B261F, 표면 #4A3228, 본문 #FFF5E8, 버튼 #F2D6AE, 버튼 글씨 #2B1B15를 출발점으로 대비 검증. 본문 20px 이상, 제목 28~32px, 버튼 높이 60px 이상. 한 화면 한 행동. 자동 음성/음악/자동 전환 없음. 글씨 확대, 명확한 포커스, 스크린리더 레이블, 항상 이전/방 목록 버튼. 터치만으로 문장 넘기지 않고 명시적 버튼 사용.
